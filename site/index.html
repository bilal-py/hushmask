Tell the AI everything except who you are.

hushmask hides names, card numbers, accounts and other personal details before your text reaches an AI, then puts them back in the answer. It runs on your machine, and any app that talks to OpenAI-style APIs can use it by changing one URL.

Type or paste anything. Highlighted values never leave your machine; the right side is exactly what an AI provider would receive. This demo runs in your browser with hushmask's pattern rules. Nothing is sent anywhere.

    Hides who. Keeps what.
    
      
    Hiding everything is easy and useless: an AI that can't see "SWIGGY 450.00" can't tell you that you spent it on food. hushmask hides the person and leaves the task.
    
      
    
        
    People
    Your own name from your list, and anyone else's from a local names model. "Mr Sharma" links to "Rahul Sharma" so the AI knows it's the same person.
    
        
    Numbers that identify you
    Cards (Luhn-checked), IBANs (mod 97), Aadhaar (Verhoeff), PAN, IFSC, and account numbers labelled as such. A random number that fails the checksum is left alone.
    
        
    Ways to reach you
    Emails, phone numbers in Indian and international formats, UPI IDs like name@okhdfcbank, IP addresses.
    
        
    Where you live
    Street addresses from your list or the names model. Cities only in the strict preset: on a statement they're part of the merchant.
    
      
    
      
    Stays readable: merchants, amounts, dates, currencies and words like NEFT, UPI or refund. Same value, same token, every time, so a whole conversation stays consistent and the provider's prompt cache keeps working.
    
    
    
  
    

  
  
    
    
    
      
    Measured, not promised.
    
      
    "Privacy-first" is easy to say. These are the share of personal values fully hidden on labelled data, with every setup, including the ones that look bad.

      Running in a few minutes.
      
      
      Python 3.12 and uv. The names model is optional and heavy (about 1.7 GB with PyTorch), so it's a separate extra.
      
      
      
        
      
          
      
            
      Install and start
      
            
      git clone https://github.com/bilal-py/hushmask
cd hushmask
uv sync --extra proxy --extra ner
cd web && npm install && npm run build && cd ..
uv run hushmask serve
      
          
      
          
      
            
      Just try it on a file
      
            
      uv run hushmask mask statement.txt \
  --known "PERSON=Your Name" --preset finance --ner
      
          
      
        
      
        
      
          
      
            
      Point any OpenAI client at it
      
            
      from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8700/v1",  # was https://api.openai.com/v1
    api_key="hm-yourapp-...",             # the app's hushmask key
)
reply = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": statement}],
)
print(reply.choices[0].message.content)  # real names back
      
          
      
          
      Then open http://127.0.0.1:8700/dashboard/ to add apps (OpenAI, Gemini, Ollama, OpenRouter, Groq or any compatible URL), choose what each one hides, and copy its key.
      
        
      
      
      
    
      
  
      

  
  
      
    
      
      
      Rules it doesn't bend.
      
      
      
        
      Fails closed
      After masking, the text is scanned again. If anything detectable is still visible, the request is refused instead of sent.
      
        
      Real values stay in memory
      The map from tokens to values lives for the request. Logs and stats hold counts, never values.
      
        
      Won't send what it can't mask
      Images, audio and files are refused unless you allow them for an app, because there's no way to hide what's in them.
      
        
      Dashboard is yours alone
      It only answers on localhost and needs a header other websites can't add, so a page in another tab can't read your apps.
      
      
      
    
      
  
      

  
  
      
    
      
      
      Good to know
      
      
      
        
      Is this anonymization?
      No. It hides who you are from the AI provider. Merchants, amounts, dates and places stay visible on purpose, and in combination they can still say a lot. If you need data nobody could ever link back to a person, this isn't that.
      
        
      Which AI providers work?
      Anything that speaks the OpenAI chat-completions API: OpenAI, Gemini's OpenAI-compatible endpoint, Ollama, OpenRouter, Groq, LM Studio and others. Each app in the dashboard can use a different one.
      
        
      Does it work with streaming?
      Your app can ask for a stream and it will work, but hushmask waits for the whole answer before sending it on. A token split across two chunks couldn't be put back reliably.
      
        
      What if the AI changes a token?
      Tokens are restored even if the model changes their case. A token the AI invents, or one hushmask never sent, is left as it is and counted, so you can see it in the dashboard.
      
        
      Does it need the internet?
      Only to reach the AI you choose, and once to download the names model. With Ollama, everything stays on your machine.
      
        
      Who's it for?
      Anyone who wants to use cloud AI on personal text without handing over who they are. It started as the privacy layer for Spence, a local-first expense tracker, and works with any app.
